## 먼저 — 「초기비용 항목표」는 1주차에서 뺍니다

**본인 지적이 맞아요.** 공실을 얻어서 하나하나 세팅한 게 아니라 **기존 가게를 인수**했으니까,
"공실 창업 비용표"는 경험이 아니에요. 그걸 쓰면 금방 티가 납니다.

### 근데 그게 오히려 더 좋은 각도예요

| | |
| --- | --- |
| 흔한 콘텐츠 | 공실 얻어서 인테리어하고 장비 넣는 비용 |
| **채채만 가능** | **기존 가게를 권리금 주고 인수했을 때 드는 돈** |

**뷰티샵 창업은 실제로 인수가 더 많아요.** 그런데 콘텐츠는 전부 공실 기준이에요.
그래서 이건 **3주차(계약 주)에 「매물 인수할 때 드는 돈」으로** 붙입니다. 권리금 이야기랑 같이 가야 해요.

**창업비용 계산기는 그대로 써도 됩니다.** 권리금 입력란이 있고
"권리금은 나갈 때 그대로 받기 어렵다"는 안내까지 들어가 있어요. 인수 케이스를 이미 커버해요.

# 릴스 ② 기술은 배웠는데 손님이 0명일 때 (약 35초)

> 이번 주 **주력**이에요. 저장·댓글이 제일 많이 나올 편.

### 훅 (0~5초)

> 자격증은 땄는데 손님이 0명이잖아.
> 나도 그랬어. 진짜 한 명도 없었어.

자막 — `손님 0명에서 시작`

**시청자의 현재 상태로 열어요.** 이게 프레임워크 4번(공감 후킹)이에요.
"나는 8만 원 받아"로 열면 남의 얘기고, "나도 0명이었어"로 열면 내 얘기가 됩니다.

### 전개 (5~25초) — 사다리를 숫자로

> 속펌 수업 끝나자마자 연습할 데가 없어서 베드쉐어부터 구했어. **4개월 했어.**
> 거기서 모델 구해서 **무료로** 했어.
>
> 그다음 **3만 원** 받고 서너 명,
> **5만 원**으로 올려서 손님 받고,
> 그러고 **8만 원 정가**가 됐어.

자막 — `무료 → 3만 → 5만 → 8만`

<!-- 본인이 채울 것 -->
**각 단계 몇 명쯤 하고 올렸는지 숫자를 넣으세요.** 그게 이 영상의 핵심 정보예요.
"무료 ○명 → 3만 원 ○명 → 5만 원 ○명" 이렇게 나오면 **따라 할 수 있는 지도**가 됩니다.

### 마무리 (25~35초) — 나만의 관점

> 처음부터 정가 받으려고 하면 아무도 안 와.
> **가격을 올릴 자격은 손님 수가 만들어주는 거더라.**
>
> 기술 배우고 샵 차리기까지 내가 거친 순서, 전부 정리해놨어.
> 댓글에 `순서` 남겨주면 보내줄게.

자막 — `가격을 올릴 자격은 손님 수가 만들어준다`

**이 문장이 저장됩니다.** 숫자만 나열하면 안 저장되고, 거기서 뽑은 관점이 저장돼요.

# 카드뉴스 ① 기술 배우고 내 샵 차리기까지 7단계 (목)

**전체 지도를 한 장에.** 순서를 모르는 사람이 제일 많이 저장하는 포맷이에요.

```
1장   기술 배우고 내 샵 차리기까지, 내가 거친 순서
2장   9월 — 직장 다니면서 반영구 수강 시작
3장   수강 중 — 새벽 4시까지 연습, 점심시간엔 구석에서
4장   +2개월 — 과정 끝나고 바로 실습
5장   연습할 데가 없어서 베드쉐어를 구함 (4개월)
6장   무료 모델 → 3만 → 5만 → 8만 정가
7장   11월 — 퇴사, 근데 같은 회사 주 3일 알바로
8장   샵인샵 3개월 계약
9장   23살, 14평 내 가게
10장  "순서를 몰라서 못 하는 거지, 어려워서 못 하는 게 아니더라"
      전체 정리본은 댓글에 '순서'
```

- **한 장에 한 단계만.** 두 개 넣으면 아무것도 안 남아요
- 10장의 문장이 **공유되는 지점**이에요

# 카드뉴스 ② 무료 모델에서 정가 8만 원까지 (일)

릴스 ②를 못 본 사람을 다시 걸고, **자료로 보냅니다.**

```
1장   무료 모델에서 정가 8만 원까지, 단가 올린 순서
2장   기술 배우면 끝인 줄 알았는데, 연습할 데가 없었다
3장   0단계 — 연습 공간부터 (나는 베드쉐어를 구했다)
4장   1단계 — 무료 모델. 돈 생각 말고 사람 수를 쌓는 구간
5장   2단계 — 3만 원. 처음 돈 받는 구간
6장   3단계 — 5만 원. 여기부터 '손님'이 된다
7장   4단계 — 8만 원 정가
8장   올리는 타이밍은 ○○으로 판단했다   ← 본인이 채울 것
9장   "처음부터 정가 받으려고 하면 아무도 안 온다"
10장  저장해두고 지금 단계 확인해보세요
      전체 순서는 댓글에 '순서'
```
