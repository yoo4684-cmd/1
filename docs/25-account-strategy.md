## ⚠️ 선행 확인 1건 — 양도 계약

**샵 양도 시 인스타 계정이 양도 목록에 포함됐는지.**

권리금·양도 계약에 `상호 / SNS 계정 / 고객 명부`가 포함되는 사례가 흔함.
포함돼 있었다면 지금 사용하는 것이 **계약 위반**.

→ 계약서 확인 전까지 프로필 변경 보류. 이것만 통과하면 나머지는 진행 가능.

## 팔로워 이탈은 손해가 아님

| 구분 | 누구 | 프로필 변경 후 |
| --- | --- | --- |
| A | 그 샵 **손님** | 이탈 — 어차피 갈 가게가 없음 |
| B | 가림막 릴스 유입 **원장** | **잔류 = 제품 고객** |

A의 이탈은 **명단 정리**. 남은 사람의 관련도가 올라가 노출에 오히려 유리.
언팔 수치에 흔들리지 말 것.

## 계정 3개 운영 금지 — 역할 분담

혼자 3개는 2주 내 붕괴. **BESY 오피셜은 11월에 콘텐츠를 올리지 않는다.**
팔로워 0인 브랜드 계정에 올려봐야 도달이 없음. 간판 역할이면 충분.

| 계정 | 11월 역할 | 빈도 |
| --- | --- | --- |
| **샵 계정** | 제품 개발 과정 + 펀딩 (현업 원장) | **메인** · 주 3~4 |
| **@chaechae.do** | 창업노트 시리즈 (예비창업자) | 주 2로 감축 |
| **BESY 오피셜** | 프로필 태그 · 펀딩 오픈 공지 · 고객 응대 | 콘텐츠 없음 |

펀딩 종료 전까지는 **샵 계정이 매출 쪽**. @chaechae.do는 장기 자산이라 속도를 늦춰도 됨.

## 샵 계정 프로필 (초안)

```
[이름 필드]  ← 인스타 검색에 걸리는 곳
채채 | 왁싱 가림막 만드는 중

[소개]
왁싱샵 3년 하다가 불편한 거 직접 고쳐서 만듭니다
시술용 가림막 겸 조명 · 11월 와디즈 오픈
만드는 과정 전부 공개 중
@besy.official
```

- **이름 필드에 `왁싱 가림막`을 박을 것.** 인스타는 이름 필드를 검색에 태움 → 원장 유입 경로
- **`3년 하다가`** — 양도 사실을 숨기지 않고 **"해봤으니 안다"**로 전환.
  현업 원장에게는 이게 가장 강한 자격 증명
- BESY 오피셜 핸들은 실제 값으로 교체 필요 (현재 `@besy.official`은 가정)

### 왜 터진 릴스 분석이 먼저인가

"터졌다"는 건 그 콘텐츠가 **원장들의 실제 불편을 정확히 건드렸다**는 뜻.
무엇이 먹혔는지 알면 제품 콘텐츠 전체를 거기 맞출 수 있음.
댓글은 docs/05에서 말한 **"의견이 반영된 제품은 안 살 수가 없다"**의 원재료이기도 함.
