# 카드뉴스 ① — 뷰티샵 차리고 싶은데 뭐부터 해?

> 릴스 2편과 같은 주. 키워드 **`순서`** 로 수렴.

---

## 릴스 2편과 역할을 나눈다

| | 다루는 것 |
| --- | --- |
| **릴스 2편** | 전체 중 **한 구간**(단가 올리기)을 깊게 |
| **카드뉴스** | **전체 지도** 7단계를 한 번에 |

같은 걸 두 번 하면 둘 다 약해진다. **릴스는 깊게, 카드는 넓게.**
그리고 **전체 지도형이 저장이 제일 잘 된다.** "순서를 모르겠다"가 예비창업자 1번 고민이라서.

---

## 카드 10장

### 1장 — 표지

```
뷰티샵 차리고 싶은데
뭐부터 해?

내가 거친 순서 7단계
```

**타깃의 질문을 그대로** 쓴다. 피드에서 보이는 건 이 장 하나뿐이다.

### 2장 — 왜 이걸 쓰는지

```
나는 23살에 왁싱샵 차려서 지금 3년 차야.

근데 시작할 땐 물어볼 사람이 한 명도 없었어.
검색하면 조각조각은 나오는데
전체 순서를 알려주는 데가 없더라고.

그래서 처음부터 끝까지,
내가 거친 순서 그대로 적어둘게.

👉 저장해두고 하나씩 봐
```

<!-- 2026-10-29 수정 -->
**자격(23살 창업 / 3년 차)을 추가했다.** 캐러셀만 보는 사람은 릴스를 안 봤을 수 있어서
"넌 누군데?"가 먼저 걸린다. 2장이 해야 할 일은 셋이다 —
**① 누구인지 ② 왜 만들었나 ③ 저장해둬.**

양도("넘겨봤다")는 더 센 자격이지만 **여기선 쓰지 않는다.**
이 카드뉴스는 *차리기까지*의 순서라, 양도를 꺼내면 초점이 흐려진다.

**`검색하면 조각조각은 나오는데 전체 순서를 알려주는 데가 없더라고`** 를 가운데 넣었다.
"없었어 → 적어둘게"로 바로 점프하면 **왜 하필 '순서'인지**가 비기 때문이다. 이 한 줄이
① 이 카드뉴스가 왜 필요한지 설명하고 ② 보는 사람이 "나도 검색했는데 조각만 나왔어"로 공감하고
③ **'전체 순서'라는 차별점**을 박는다.

<!-- 실무 -->
**2장에 저장 유도를 미리 깐다.** 끝까지 안 넘긴 사람도 여기서 저장한다.

### 3장 — 1단계

```
1. 뭘 배울지 정하기

나는 반영구부터 시작했어.
근데 처음 간 아카데미는 별로였고,
그래서 두 번 돈 썼어.

→ 학원은 '실습 몇 번 시켜주는지'부터 물어봐
```

### 4장 — 2단계

```
2. 직장 다니면서 배우기

치과 다니면서 배웠어.
새벽 4시까지 연습하고 7시에 출근.
점심시간엔 구석에서 몰래.

→ 수입을 끊고 시작하지 마
```

### 5장 — 3단계

```
3. 연습할 공간 만들기

기술 배우면 끝인 줄 알았는데
연습할 데가 없더라.

나는 베드쉐어를 구했어. 4개월.

→ 여기서 포기하는 사람이 제일 많아
```

### 6장 — 4단계

```
4. 무료 모델부터

돈 생각 말고 사람 수를 쌓는 구간이야.

처음부터 정가 받으려고 하면
아무도 안 와.
```

### 7장 — 5단계

```
5. 단가 올리기

무료 → 3만 원 → 5만 원 → 8만 원

한 번에 안 올렸어.
사람이 쌓일 때마다 한 칸씩.
```

### 8장 — 6단계

```
6. 퇴사 + 샵인샵

9월에 배우기 시작해서 11월에 퇴사.
근데 한 번에 안 끊었어.
같은 회사 주 3일 알바로 돌리면서
샵인샵부터 시작했어.

→ 바로 상가 가지 마
```

### 9장 — 7단계

```
7. 내 가게

샵인샵 3개월 해보고
"이제 해도 되겠다" 싶을 때 계약했어.

23살, 잠실 14평.
첫 달 매출 480만 원.
```

### 10장 — 마무리 + CTA

```
순서를 몰라서 못 하는 거지
어려워서 못 하는 게 아니더라.

7단계 전체 정리본 보내줄게
👉 댓글에 '순서'
```

## 만들 때

- **한 장에 한 단계만.** 두 개 넣으면 아무것도 안 남는다
- **1080×1350 (4:5)** 로 만든다. 1:1보다 **피드에서 더 크게 보인다**
- 글자는 생각보다 크게. 피드에서는 작게 보인다
- **3~9장 디자인을 똑같이.** 숫자와 텍스트만 바꾸면 7장이 10분 만에 나온다
- 캔바/미리캔버스 템플릿 하나 만들어두고 재사용
