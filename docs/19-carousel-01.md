# 카드뉴스 ① — 뷰티샵 차리고 싶은데 뭐부터 해?

> 릴스 2편과 같은 주. 키워드 **`순서`** 로 수렴.

---

## 릴스 2편과 역할을 나눈다

| | 다루는 것 |
| --- | --- |
| **릴스 2편** | 전체 중 **한 구간**(단가 올리기)을 깊게 |
| **카드뉴스** | **전체 지도** 7단계를 한 번에 |

같은 걸 두 번 하면 둘 다 약해진다. **릴스는 깊게, 카드는 넓게.**
그리고 **전체 지도형이 저장이 제일 잘 된다.** "순서를 모르겠다"가 예비창업자 1번 고민이라서.

---

## 카드 10장

### 1장 — 표지

```
뷰티샵 차리고 싶은데
뭐부터 해?

내가 거친 순서 7단계
```

**타깃의 질문을 그대로** 쓴다. 피드에서 보이는 건 이 장 하나뿐이다.

### 2장 — 왜 이걸 쓰는지

```
나는 23살에 왁싱샵 차려서 지금 3년 차야.

근데 시작할 땐
물어볼 사람이 한 명도 없었어.

그래서 내가 겪은 거
여기서 최대한 다 알려주려고.

오늘은 일단
뷰티샵 창업 전체 순서부터.

👉 저장해두고 하나씩 봐
```

<!-- 2026-10-29 수정 -->
**자격(23살 창업 / 3년 차)을 추가했다.** 캐러셀만 보는 사람은 릴스를 안 봤을 수 있어서
"넌 누군데?"가 먼저 걸린다. 2장이 해야 할 일은 셋이다 —
**① 누구인지 ② 왜 만들었나 ③ 저장해둬.**

양도("넘겨봤다")는 더 센 자격이지만 **여기선 쓰지 않는다.**
이 카드뉴스는 *차리기까지*의 순서라, 양도를 꺼내면 초점이 흐려진다.

가운데를 **두 층**으로 나눴다.

| | 역할 |
| --- | --- |
| **앞으로** 최대한 다 알려주려고 | **계정을 팔로우할 이유** |
| **오늘은 일단** 전체 순서부터 | **이 콘텐츠의 범위** + 다음 편 암시 |

`일단 ~부터`가 핵심이다. **다음이 있다는 신호**라서 한 편짜리가 아니라 시리즈로 읽힌다.

<!-- 실무 -->
**2장에 저장 유도를 미리 깐다.** 끝까지 안 넘긴 사람도 여기서 저장한다.

### 3장 — 1단계

```
1. 뭘 배울지 정하기

나는 반영구부터 시작했어.
근데 처음 간 아카데미는 별로였고,
그래서 두 번 돈 썼어.

→ 대표원장이 전체 수업을 다 하는지 물어봐
```

### 4장 — 2단계

```
2. 직장 다니면서 배우기

치과 다니면서 배웠어.
새벽 4시까지 연습하고 7시에 출근.
점심시간엔 구석에서 몰래.

→ 배우자마자 나오고 싶어져.
   근데 그때가 제일 위험해
```

**왜 이 팁인가** — 기술을 배우기 시작하면 **빨리 나와서 차리고 싶어진다.**
배우는 사람이면 다 겪는 감정인데 **아무도 그걸 위험하다고 말해주지 않는다.**
`그때가 제일 위험해`가 멈추게 한다.

시간 관리 팁(퇴근 후 바로 가기 등)은 **창업 콘텐츠가 아니라 자기계발 콘텐츠**다.
여기서 할 말은 **"직장을 최대한 유지하라"**는 쪽이다. 자세한 건 자료로. → 아래

### 5장 — 3단계

```
3. 연습할 공간 만들기

기술 배우면 끝인 줄 알았는데
연습할 데가 없더라.

나는 베드쉐어를 구했어. 4개월.

→ 여기서 포기하는 사람이 제일 많아
```

### 6장 — 4단계

```

```

### 7장 — 5단계

```

한 번에 안 올렸어.
사람이 쌓일 때마다 한 칸씩.
```

### 8장 — 6단계

```
6. 퇴사 + 샵인샵

9월에 배우기 시작해서 11월에 퇴사.
근데 한 번에 안 끊었어.
같은 회사 주 3일 알바로 돌리면서
샵인샵부터 시작했어.

→ 바로 상가 가지 마
```

### 9장 — 7단계

```
7. 내 가게

샵인샵 3개월 해보고
```

## 만들 때

- **한 장에 한 단계만.** 두 개 넣으면 아무것도 안 남는다
- **1080×1350 (4:5)** 로 만든다. 1:1보다 **피드에서 더 크게 보인다**
- 글자는 생각보다 크게. 피드에서는 작게 보인다
- **3~9장 디자인을 똑같이.** 숫자와 텍스트만 바꾸면 7장이 10분 만에 나온다
- 캔바/미리캔버스 템플릿 하나 만들어두고 재사용

# 자료 — 0단계 「어디서 배울지 고르기」

> 리드 마그넷 「기술 배우고 내 샵 차리기까지, 전체 순서」의 0단계.
> 카드뉴스 3장은 이 중 1번만 꺼낸 것.

```
1. 대표원장이 전체 수업을 다 하는지
   간판만 대표원장이고 실제론 강사가 가르치는 데가 있어.
   물어보면 바로 알아.

2. 수강생 작업물과 후기를 꼼꼼히
   학원 인스타엔 원장 작업물만 올라와.
   근데 내가 배우면 되는 건 수강생 수준이야.
   후기도 한두 개 말고 전부 읽어봐.

3. 비교군을 넓혀 — 알고리즘을 써먹는 법
   수강 관련 게시물을 계속 보면
   인스타가 비슷한 학원을 알아서 띄워줘.
   그 상태로 2~3주 두고, 계속 뜨는 곳들을 모아서 비교해.
   검색 한 번 해서 나오는 상위 몇 개로 정하지 마.

4. 크고 화려한 곳이 답은 아니야
   새로 시작한 곳이 오히려 한 명 한 명 꼼꼼히 봐줘.
   규모가 크면 수강생이 많아서 손이 덜 가.

5. 싼 데보다 제대로 알려주는 데
   여러 개 배울 수 있고 싼 곳보다,
   하나라도 제대로 가르치는 곳.
   두 번 배우면 결국 더 비싸. 내가 그랬어.

6. 결국 방문 상담
   인스타로 보이는 건 보이는 것뿐이야.
   공간, 분위기, 원장이 어떻게 말하는지 —
   가보면 느낌이 와.
```

## 메모

- **3번이 제일 값지다.** "알고리즘을 만들어서 비교한다"는 아무도 안 쓰는 방법이고
  **읽자마자 따라 할 수 있다.** 자료 안에서 제일 많이 캡처될 항목.
- **5번의 `내가 그랬어`를 지우지 말 것.** 정보에 경험이 붙어야 설득력이 생긴다.
- 4번은 **단정하지 말 것.** "답은 아니야" 정도로. 새 학원이 무조건 낫다는 건 아니고,
  규모가 선택 기준이 아니라는 뜻이다.
- ⚠️ 어디서도 **특정 학원을 지목하지 않는다.**

# 자료 — 2단계 「직장 다니면서 배우기」

```
배우기 시작하면 이상하게 빨리 나오고 싶어져.
손에 뭐가 좀 붙는 것 같고, 지금이면 될 것 같고.
나도 그랬어.

근데 그건 실력이 아니라 기분이야.

직장은 최대한 끝까지 붙어 있어. 이유는 두 개야.

하나, 창업은 결국 돈이야.
직장 다니는 동안이 제일 많이 모을 수 있는 시기야.
나와서 모으려고 하면 못 모아.

둘, 수입이 있어야 판단이 안 흐려져.
돈이 없으면 급해지고, 급하면 아무 매물이나 잡아.

나올 타이밍은 감정 말고 이걸로 정해.
· 정가 받는 손님이 꾸준히 있는가
· 몇 달 버틸 돈이 있는가
· 나와서 바로 뭘 할지 정해졌는가

나는 퇴사하고도 주 3일은 알바로 나갔어.
완전히 끊은 게 아니야.
```

## 메모

- **`그건 실력이 아니라 기분이야`** 가 이 섹션에서 제일 많이 캡처될 문장이다.
- 마지막 **`나는 퇴사하고도 주 3일은 알바로 나갔어`** 를 지우지 말 것.
  말로 끝내지 않고 **본인이 실제로 그렇게 했다는 증거**라 설득력이 달라진다.
- 체크리스트 3개(손님·돈·다음 계획)가 **"감정이 아니라 기준으로 정하라"**를 실행 가능하게 만든다.
