# 타깃 고정 — 뷰티샵 사람만 모은다

> 2026-10-24 결정. **돈·부업 관심자는 타깃이 아니다.**
> 이 문서가 앞선 문서들의 훅·해시태그·일부 소재 선정을 **덮어쓴다.**

---

## 내가 틀렸던 것

**"연봉 2,400 → 1억" 훅을 유지하자고 한 게 틀렸다.**

멈춤력이 세다는 이유로 추천했는데, 그 훅이 데려오는 사람이 정확히
**돈·부업 관심자**다. 지금 목표는 조회수가 아니라 **뷰티샵 사람**이다.

같은 이유로 **「회사 언제 그만둬야 하냐면」(퇴사 타이밍) 편도 타깃이 어긋난다.**
"타깃을 넓히는 편"이라고 추천했는데, **지금은 넓히는 게 손해다.**

---

## 필터링 원칙 — 훅에 업종 단어를 박는다

지금 콘텐츠가 전부 **업종 중립**이라서 부업 관심자가 온다.

| ❌ 업종 중립 (부업러가 옴) | ✅ 업종 명시 (뷰티샵 사람이 옴) |
| --- | --- |
| 연봉 2,400 → 1억 | 23살에 왁싱샵 차려서 3년 |
| 퇴사 타이밍 | 뷰티 기술 배우고 샵 차리기까지 |
| 단가 올리는 법 | **시술** 단가 올리는 법 |
| 초기비용 항목표 | **뷰티샵** 매물 인수 비용 |
| 손님이 0명일 때 | **기술 배웠는데** 손님이 0명일 때 |

> **업종 단어를 넣으면 조회수는 줄고 전환은 오른다. 그게 지금 원하는 거다.**

**조회수 목표를 버려야 한다.** 1만 팔로워는 이 타깃으로 어렵다.
**1,000명이 전부 뷰티샵 사람이면 그게 훨씬 값지다.**

## 첫 릴스 수정

### 훅 — 1억을 빼는 게 아니라 뒤로 민다

**지금**
```
퇴근하고 집에 오면 아무것도 하기 싫잖아.
근데 나는 그때 학원을 갔어.
그게 2년 뒤에 연봉 1억이 될 줄은 몰랐지.
```

**바꾸면**
```
퇴근하고 집에 오면 아무것도 하기 싫잖아.
근데 나는 그때 반영구 학원을 갔어.

그게 2년 뒤에 왁싱샵 사장이 될 줄은 몰랐지.
```

- `학원` → **`반영구 학원`**: 3초 안에 업종이 박힌다
- `연봉 1억` → **`왁싱샵 사장`**: 미끼를 돈에서 업종으로 교체

**1억을 버리는 게 아니다.** 0:35 숫자 구간에 그대로 남는다.
이미 들어온 사람에게 주는 **보상**이지, 끌어오는 **미끼**가 아니게 되는 것뿐이다.

### 썸네일 — 1억을 뺀다

```
왁싱샵 3년 하다가
지금은 제품 만드는 중
```

프로필 그리드가 **"뷰티샵 계정"으로 읽혀야 한다.** `1억`이 박혀 있으면 돈 계정이다.
이 문구는 계정의 두 축(**창업 경험 + 제품**)을 한 번에 말한다.

**대안** — `23살에 왁싱샵 차려서 / 3년 해본 얘기`

### 해시태그 — 두 개는 반드시 뺀다

**지금**
```
#일단해보는01년생 #23살창업 #왁싱샵창업 #직장인부업
#퇴사준비 #내일만들기 #1인샵 #여자창업 #사장일기
```

🔴 **`#직장인부업` `#퇴사준비`는 정확히 원하지 않는 사람을 부른다.**
해시태그는 알고리즘한테 보내는 **타깃팅 신호**다.

**바꾸면**
```
#왁싱샵 #왁싱샵창업 #뷰티샵창업 #1인샵창업 #반영구
#속눈썹연장 #에스테틱창업 #뷰티샵사장 #일단해보는01년생
```

## 🚨 제품 구매자는 콘텐츠로 못 모은다

여기가 제일 중요하다.

| | 콘텐츠로 모이는 사람 | 가림막을 살 사람 |
| --- | --- | --- |
| 누구 | 뷰티샵 **창업 준비·초기** | **현업 왁싱샵 원장** |
| 지금 | 가게 없음 | 가게 있음 |
| 가림막 | **지금은 못 삼** | 바로 삼 |

**둘은 시간이 지나면 겹치지만, 펀딩은 몇 주 안이다.**
지금 모으는 사람은 **지금 가림막을 못 산다.**

### 현업 원장은 직접 찾아야 한다

왁싱샵 원장은 **모수가 적다.** 인스타 자연 유입을 기다리면 펀딩 전에 못 모은다.

```
① 해시태그로 계정 찾기
   #왁싱샵 #브라질리언왁싱 #왁싱샵추천 #지역명+왁싱
   → 원장 계정이 그대로 나온다

② 팔로우 + 게시물 반응 (며칠)

③ DM — 영업이 아니라 의견 요청으로
   "원장님 안녕하세요, 저도 왁싱샵 3년 했는데
    지금 시술용 가림막을 만들고 있어요.
    혹시 쓰시면서 불편했던 거 있으세요? 제품에 반영하려고요."
```

<!-- 실행 주의 -->
**하루 20~30개씩, 복붙 말고 개별적으로.** 한꺼번에 많이 보내면
인스타 제한에 걸리고, 복붙은 바로 티가 나서 역효과다.

이 한 줄이 **시장조사 + 대기명단 + 첫 고객**을 동시에 만든다.
그리고 답장한 원장은 **자기 의견이 반영된 제품**이라 펀딩 때 거의 참여한다.

**펀딩까지 2~3주면 이게 유일하게 확실한 방법이다.**
