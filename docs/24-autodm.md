## 1. 첫인사

```
댓글 고마워요! 🙏
아래 버튼 누르면 창업노트 바로 보내드려요.
```

기본 문구(`창업 준비에 도움 될 정보와 가이드`)는 **무엇을 주는지 불명확.**
카드 10장이 약속한 이름이 `창업노트`이므로 **같은 단어**를 써야
"맞게 왔다"는 확신이 생김.

## 2. 버튼 라벨

```
창업노트 받기
```

(기본 `정보 받기` → 무엇인지 모름)

## 3. 통과 시 보상 메시지 ★ 핵심

```
댓글 고마워요! 🙏
아래 링크에 창업노트 정리해뒀어요.

뭘 배울지 정하는 것부터 내 가게 계약까지,
제가 실제로 거친 7단계예요.
잘된 것만 적은 게 아니라 후회한 것도 그대로 썼어요.

단계마다 체크리스트 있으니까
내 단계부터 찾아서 하나씩 체크해보세요.

그리고 혹시 지금 어느 쪽이세요?
① 뭘 배울지 고민 중
② 배우는 중
③ 연습 공간 찾는 중
④ 매물 보는 중

번호만 보내주셔도 돼요. 거기 맞춰서 더 알려드릴게요 :)
```

**마지막 질문의 역할 3개**

1. **DM 대화 시작** → 인스타가 '친한 사이'로 판정 → 이후 게시물 노출 상승
2. **명단 분류** → ④ 매물 보는 중 = 곧 샵 차릴 사람 = **가림막 잠재 고객**.
   docs/16의 2트랙 중 제품 트랙으로 넘길 유일한 통로
3. **답장률** → "궁금한 거 물어보세요"는 답이 거의 없음(뭘 물을지 모름).
   번호 하나는 마찰이 거의 0

> 1,000 byte 초과 시 ①~④ 설명만 축약:
> `① 고민 중 / ② 배우는 중 / ③ 공간 찾는 중 / ④ 매물 보는 중`

## 4. 팔로우 미확인 시 안내

```
앗, 아직 팔로우 확인이 안 됐어요!

창업노트 말고도 상가 계약 체크리스트, 장비 리스트 같은 자료를
계속 올릴 거라서, 팔로우해두시면 바로바로 받아보실 수 있어요.

프로필에서 팔로우하고 아래 버튼 다시 눌러주세요 :)
```

기본 문구는 **"팔로우해야 줍니다"(입장료)**로 읽힘.
이 문구는 **"팔로우하면 다음 것도 받아요"(혜택)**. 같은 요구, 다른 프레임.

---

## ⚠️ 팔로우 게이트 — 원칙과의 충돌

docs/13에서 **「팔로우를 조건으로 걸지 말 것」**으로 정했었음.
이유: 자료 때문에 팔로우한 사람은 금방 언팔 → 유령 팔로워.

Turnflow가 팔로우 확인 버튼 구조라 **구조적으로 회피 불가.**
→ 문구를 혜택 프레임으로 써서 거부감만 완화함.

### 첫 주 판단 지표

**댓글 수 대비 순증 팔로워 수.**

| 결과 | 해석 | 조치 |
| --- | --- | --- |
| 댓글 50 → 팔로워 +35 이상 | 게이트가 작동 | 유지 |
| 댓글 50 → 팔로워 +10 내외 | **게이트에서 이탈** | 다음 자료는 게이트 없이 |

언팔률도 같이 볼 것. 자료 받고 1주 내 언팔이 많으면 게이트 자체가 문제.

## 발행 전 체크

- [ ] 창업노트 **공개 링크 전환** (공유 → 웹에서 공유 ON)
- [ ] 그 링크를 「통과 시 보상 메시지」의 링크 추가에 삽입
- [ ] 첫인사 · 버튼 라벨 · 보상 메시지 · 미확인 안내 4개 전부 해요체로 교체
- [ ] 키워드 `순서` 등록 확인
- [ ] 캠페인 시작 → **카드뉴스 업로드 전에** 켜둘 것

> 자동DM이 안 걸린 상태로 올리면 댓글만 쌓이고 자료가 안 나감.
> 그러면 **다음 자료 때 아무도 댓글을 안 닮** ("저번에 안 왔잖아").
> 첫 번째 회차가 제일 중요함.
