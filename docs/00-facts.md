# 확정 사실 · 숫자 (모든 콘텐츠 공통)

> 여러 영상에 반복해서 나오는 숫자들. **여기 적힌 값이 기준**이고,
> 다른 문서와 충돌하면 이 파일이 맞다.

## 첫 가게 (뷰티샵 1인샵)

| 항목 | 값 | 비고 |
| --- | --- | --- |
| 창업 나이 | 23살 | 01년생 |
| **총 초기비용 (세팅까지)** | **약 8,000만원** | 권리금 포함 |
| 그중 권리금 | 3,800만원 | 직거래 매물 |
| 운영 기간 | 약 3년 | |
| 운영 말기 매출 | 최근 3개월 월평균 1,000만원 | |

## 가게 정리 과정

| 시점 | 권리금 호가 |
| --- | --- |
| 처음 내놓을 때 | 3,500만원 |
| 6개월 뒤부터 계속 인하 | 2,000 → 1,000만원 |
| 0원까지 생각함 | — |
| 부동산 권유로 다시 | 300만원 |
| "150만원에 안 되냐" / "싼 거면 하자 있는 거 아니냐" 반응 | — |
| 열받아서 다시 올림 | 500만원 |
| 안 나간 총 기간 | 약 1년 |
| 최종 양도 | 600만원 |

## 표현 규칙

- "세팅까지 **8,000만원**" — 보증금 포함 여부는 영상에서 굳이 쪼개지 않는다.
  쪼갤 일이 생기면 "그중 권리금만 3,800만원"으로 말한다.
- "3,800만원 → 600만원" 이 이 계정의 **대표 숫자 쌍**이다. 반복해서 쓴다.
- 0원까지 생각했던 건 사실이지만, **실제로 0원에 내놓은 적은 없다.**
  "0원에라도 넘기려고 했다"로 말해야 정확하다.

## 이력 (콘텐츠 소재)

치위생과 졸업 → 치과 취업 → 퇴근 후 반영구 연습 → 샵인샵 →
퇴사 → 알바 병행 → 상가 계약 → 1인샵 운영 3년 → 양도 →
**현재: 제품 개발 (공장 → 샘플 → 특허 → 인증 → 생산 → 펀딩)**
