## 먼저 — 가져올 것과 안 가져올 것

레퍼런스는 **자기소개 + 모임 모집**이다. **정보형이 아니다.**
그 구조를 그대로 쓰면 1편 릴스(자기소개)와 **내용이 겹친다.**

| | |
| --- | --- |
| ✅ **가져올 것** | **디자인 언어** — 질감 배경, 날것 사진, 손글씨 혼용, UI 목업 |
| ✅ **가져올 것** | **마지막 카드 CTA 구조** ← 댓글 849개를 만든 장치 |
| ❌ **안 가져올 것** | 서사 구조(어릴 때 → 커리어 → 모집). 1편과 중복 |

내용은 **7단계 그대로**, 옷만 갈아입힌다.

## 레퍼런스가 잘한 것 4가지

1. **카드마다 배경이 다르다** — 노트 / 버건디 / 흰 종이 / 사진 풀블리드 / 패브릭.
   7장을 넘기는데 안 지루하다. **같은 템플릿 반복이 아니다.**
2. **사진을 날것처럼 붙였다** — 비닐에 넣은 듯한 질감, 기울임, 폴라로이드 프레임.
   예쁘게 정렬한 사진보다 **"진짜 내 앨범"** 느낌이 난다.
3. **손글씨를 덧댔다** — 인쇄체 위에 손으로 쓴 메모·화살표·동그라미.
   이게 **"사람이 만든 것"** 느낌을 만든다.
4. **UI를 목업으로 썼다** — 트윗 카드, 댓글 말풍선, iOS 메모앱.
   말로 "반응이 많았다"고 하는 대신 **보여준다.**

## 카드별 레시피

### 1장 — 표지

```
배경   본인 사진 풀블리드 (살짝 어둡게)
라벨   01년생 창업기록        ← 검은 박스 + 흰 글씨 (1편 커버와 동일)
제목   뷰티샵 차리고 싶은데
       뭐부터 해?             ← 굵은 고딕, 아주 크게, 흰색
보조   내가 거친 순서 7단계    ← 형광 옐로우 하이라이트
요소   말풍선 하나 + 손그림 화살표
```

레퍼런스 1장을 거의 그대로 가져온 구성이다. **제목이 화면의 절반**을 먹어야 한다.

### 2장 — 왜 쓰는지

```
배경   크래프트 베이지 단색
상단   돌이켜보면,              ← 손글씨, 작게
본문   나는 물어볼 사람이 없어서
       순서를 몰라 제일 헤맸어
사진   그때 사진 1~2장을 기울여서 붙이기 (마스킹 테이프 요소)
하단   👉 저장해두고 하나씩 봐   ← 형광 하이라이트
```

### 3~9장 — 1~7단계 (틀 하나로 7장)

```
배경   크래프트 베이지 (또는 사진 + 어두운 오버레이)
좌상   01  ← 아주 크게, 연한 색, 배경처럼
제목   뭘 배울지 정하기        ← 굵은 고딕
본문   (내용 2~3줄)
밑줄   → 학원은 '실습 몇 번'부터 물어봐   ← 형광 하이라이트
```

<!-- 제작 핵심 -->
**이 한 장을 완성한 뒤 7번 복제하고 숫자·텍스트만 바꾼다.**
7장이 10분 안에 나온다. 매번 디자인하면 두 번째 카드뉴스를 못 만든다.

**사진이 있는 단계만** 배경을 사진으로 바꾼다 (2·3·7단계). 나머지는 단색.
→ 레퍼런스처럼 **배경이 중간중간 바뀌어서** 안 지루해진다.

### 10장 — CTA ⭐ 레퍼런스에서 제일 훔칠 만한 카드

레퍼런스 7/7이 **댓글 849개**를 만든 구조다. 그대로 쓴다.

```
배경   종이 질감
제목   [01]
       순서를 몰라서 못 하는 거지
       어려워서 못 하는 게 아니더라

목업   ───── 메모 앱 UI ─────
       7단계 전체 정리본, 하나씩 만들어서 올릴게요.

       필요하신 분은 댓글에 '순서' 남겨주세요.

       어떤 게 제일 막히는지 먼저 듣고
       거기 맞춰서 더 만들어볼게요.

       응원의 팔로우도 부탁드려요 🤍
       ─────────────────
```

**왜 이게 먹히나**

| 장치 | 효과 |
| --- | --- |
| 메모앱 목업 | 광고가 아니라 **개인 메모**로 읽힘 → 경계가 풀림 |
| "먼저 듣고" | 주는 사람이 아니라 **같이 만드는 사람**이 됨 |
| 댓글 요청이 **마지막** | 끝까지 본 사람만 댓글 → 질 높은 명단 |
| "응원의 팔로우" | 부탁조라 **부담이 없음** |

## 제작 순서

1. **10장 뼈대부터** — 배경색과 텍스트만. 꾸미지 말고 먼저 다 채운다
2. **3~9장 틀 하나 완성 → 복제 7번** — 여기서 시간을 번다
3. **사진 얹기** — 있는 것만. 없으면 안 넣는다
4. **마지막에 손글씨·스티커** — 장당 **2개까지만**. 많으면 산만해진다
5. **핸드폰으로 미리보기** — 캔바 화면에선 다 읽히는데 폰에선 안 읽힌다
