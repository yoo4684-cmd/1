## STEP 1. 스토리 유형 고르기

> 💡 내 경험 중 **감정이 가장 크게 움직였던 순간**을 떠올리고, 아래 8가지 중 하나를 고르세요.

| 유형 | 이런 이야기 |
| --- | --- |
| 내 이야기 | 내가 이 일을 시작한 이유(WHY) |
| 인생의 전환점 | 모든 게 바뀐 결정적인 순간 |
| 자기소개 | 나는 누구고 어떻게 여기까지 왔는지 |
| 비포 애프터 | X개월 전과 지금의 차이 |
| 돌파구 | 막혀 있다가 뚫어낸 순간 |
| 목표·꿈 도전기 | 지금 도전 중인 목표와 과정 |
| 시련 극복 | 힘들었던 일과 버틴 방법 |
| 성과 자랑 | 눈에 보이는 결과와 그 뒤 이야기 |

## STEP 2. 대본 구조 정하기

> 💡 아래 템플릿의 **( ) 안만 내 이야기로 채우면** 대본이 완성됩니다.

### ① 역경 – 성공 서사

📍 **이럴 때**: 내 상품·서비스가 태어난 계기를 보여주고 자연스럽게 판매로 이어가고 싶을 때.
주인공은 나일 수도, 내 고객일 수도 있습니다.

| 단계 | 역할 |
| --- | --- |
| 1. 도입 | 주인공(나 또는 고객)과 문제 소개 |
| 2. 전환점 | 문제에서 오는 고통 |
| 3. 상승 | 해결하려다 실패한 시도 |
| 4. 절정 | 해결책 등장 |
| 5. 하강 | 해결책으로 얻은 성과 |
| 6. 결말 | 내 사업·서비스로 CTA |

🔑 **핵심 포인트**
- 3단계 '실패한 시도'를 구체적으로 쓸수록 공감이 커진다. 보는 사람도 같은 방법을 써봤을 가능성이 높기 때문.
- 4단계에서 해결책을 밝힐 때 **'딱 하나'라고 좁히면** 주목도가 올라간다.
- 6단계 CTA는 강하게 팔기보다 **'저 같은 분들을 돕고 있다'**는 어조가 자연스럽다.

### ② 위기 극복 스토리

📍 **이럴 때**: 평범한 일상에서 예상치 못한 일을 겪고 더 나은 사람이 된 이야기.
드라마처럼 감정 곡선이 뚜렷해서 **끝까지 보게 만드는 힘이 가장 강하다.**

| 단계 | 역할 | 템플릿 |
| --- | --- | --- |
| 1. 시작 | 사건 이전의 삶 | X년 전 나는 평범한 (나이) (직업)이었어요. 불행하진 않았지만 뭔가 빠진 느낌이었죠 |
| 2. 계기 | 삶을 흔든 사건 | 그러던 평범한 (요일), (사건)이 터졌어요 |
| 3. 위기 | 위기 속에서 얻은 깨달음 | 그 일로 (소중한 교훈)을 깨닫게 됐어요 |
| 4. 회복 | 배운 걸 실천 | **그래서 (행동)을 시작했어요** |
| 5. 더 나은 자리 | 이전보다 나아진 지금 | 그 결과 지금은 (원하던 결과)에 (좋은 변화)까지 생겼어요 |

🔑 **핵심 포인트**
- 2단계 계기는 **'평범한 OO일'처럼 날짜나 장면을 구체적으로** 짚을수록 몰입감이 산다.
- **감정의 바닥(3단계)을 피하지 마세요.** 바닥이 깊을수록 5단계가 빛난다.

### ③ 나의 진솔한 이야기 ⭐ 프로필 고정 1번 추천 구조

📍 **이럴 때**: 계정을 처음 본 사람에게 '이 사람은 누구고, 왜 팔로우해야 하는지'를 한 번에 알려주고 싶을 때.
**프로필 고정 게시물 1번으로 가장 추천하는 구조입니다.**

| 단계 | 역할 | 템플릿 |
| --- | --- | --- |
| 1. 도입 | 이야기의 출발점 | 안녕하세요, (이름)입니다. X년 전 저는 평범한 (직업)이었어요 |
| 2. 갈등 | 이 길로 오게 된 사건 | 그런데 (삶을 바꾼 사건)이 일어났죠 |
| 3. 깨달음 | 관점이 바뀐 순간 | 그때 깨달았어요. (깨달음) |
| 4. 변화 | 깨달음 이후 한 행동과 결과 | 그래서 (행동)을 했고, 지금은 (결과)를 얻었어요 |
| 5. 목적 | 브랜드를 이끄는 진짜 이유 | **(결과)가 제 삶을 바꿨고, 이제 제 미션은 (타겟)이 (고민)에서 벗어나 (결과)를 얻도록 돕는 거예요** |

🔑 **핵심 포인트**
- 이름보다 **'무엇을 하는 사람인지'를 먼저** 말하세요. ('OO입니다'보다 '학교 다니며 회사를 차린 OO입니다')
- **5단계 목적에는 반드시 타겟을 넣으세요.** 보는 사람이 **'나를 위한 계정'**이라고 느낄 때 팔로우합니다.
- **30초 안쪽으로 짧게.** 자기소개는 **길어지는 순간 자랑이 됩니다.**

### ④ 비포 & 애프터 과정

📍 **이럴 때**: 변화 전후가 눈에 띄게 다를 때. 숫자·사진·화면으로 보여줄 수 있는 성과가 있다면 가장 설득력 있는 구조.

| 단계 | 역할 | 템플릿 |
| --- | --- | --- |
| 1. 비포 | 변화 전 모습 | X개월 만에 나는 (이전 상태)에서… |
| 2. 애프터 | 지금의 모습 | (지금 상태)가 됐어요 |
| 3. 브릿지 | 그 사이에 거친 방법 | 제가 만든 (N단계 방법)을 따랐어요. 1단계 ( ), 2단계 ( ), 3단계 ( ) / 또는: 진짜 변화는 (습관)을 바꾼 때였어요. (버린 생각)을 멈추고 (새 행동)을 시작하자 모든 게 바뀌었죠 |

🔑 **핵심 포인트**
- **비포와 애프터는 첫 3초 안에 모두 보여주세요.** 결과를 먼저 보여줘야 '어떻게?'가 궁금해진다.
- 브릿지(방법)는 **3단계 이하로.** 단계에 이름을 붙이면(예: '촬·편·올 법칙') 기억에 오래 남고 **내 브랜드가 된다.**
- 숫자는 반드시 실제 수치. **인사이트 화면 캡처를 함께 띄우면 신뢰도가 급상승.**

### ⑤ 돌파구 & 도전

📍 **이럴 때**: 남들이 잘 모르는 방법이나 요령을 찾아냈을 때. 정보를 주면서도 이야기로 풀어내기 때문에 **저장과 공유가 가장 많이 나오는 구조.**

| 단계 | 역할 | 템플릿 |
| --- | --- | --- |
| 1. 문제 | 해도 안 되던 상황 | (행동)을 계속 했는데도 여전히 (결과)가 없었어요 |
| 2. 돌파 | 판을 바꾼 깨달음·결과 | 그런데 (놀라운 결과)가 나왔어요 |
| 3. 해결법 | 호기심을 풀어주는 방법 | 어느 날 (계기)에서 (해결책)을 알게 됐고, X일 만에 (결과)가 났어요. 제가 따른 단계는 1( ), 2( ), 3( )입니다 |

🔑 **핵심 포인트**
- 1단계 문제는 **보는 사람도 겪고 있는 문제**여야 한다. **'열심히 했는데도 안 됐다'**는 말에 가장 크게 공감.
- **2단계에서 결과를 먼저 던지고, 3단계에서 방법을 풀어주세요.** 방법을 먼저 말하면 끝까지 안 본다.
- 방법은 단계별로 짧게. **화면에 1, 2, 3 자막을 띄우면 저장이 늘어난다.**

### ⑥ 인생 교훈

📍 **이럴 때**: 실패담이나 뼈아픈 경험을 솔직하게 풀고 싶을 때. **완벽해 보이는 것보다 실패를 인정하는 사람이 훨씬 더 신뢰를 얻는다.**

| 단계 | 역할 | 템플릿 |
| --- | --- | --- |
| 1. 좌절 | 충격적인 실패로 후킹 | 저는 (충격적인 사건·결과)를 겪었어요 |
| 2. 고통 | 그 실패를 만든 시행착오 | (행동1), (행동2), (행동3)을 했지만 성공하지 못했죠 |
| 3. 해결 | 결국 얻은 결과 | X개월 만에 (원하던 결과)를 얻었어요 |
| 4. 교훈 | 배운 점 | **이 일이 제게 가르쳐준 건 (교훈)입니다** |

🔑 **핵심 포인트**
- 1단계는 충격적일수록 좋다. **'망했다', '0원', '그만두라고 했다'** 같은 단어가 스크롤을 멈추게 한다.
- 2단계에서 시도한 것을 **3개 정도 나열**하면 리듬감이 생긴다.
- **4단계 교훈은 한 문장으로.** 짧고 명확한 교훈이 공유를 부른다.

### ⑦ 큰 꿈 & 인생 목표

📍 **이럴 때**: 아직 결과는 없지만 도전하는 중일 때. **성과가 없어도 만들 수 있는 유일한 구조**이고, 보는 사람을 **'응원하는 팬'**으로 만든다. **초기 계정에 특히 추천.**

| 단계 | 역할 | 템플릿 |
| --- | --- | --- |
| 1. 꿈 소개 | 오래 품어온 목표 | X살 때부터 저는 (꿈)을 꿔왔어요 |
| 2. 본격 도전 | 진짜 행동을 시작한 순간 | 몇 년을 꿈만 꾸다가, 어느 날 (계기)로 지금 아니면 안 된다고 결심했어요. (두려움)이 있었지만 그냥 했죠 |
| 3. 진행 상황 | 지금까지의 과정 + 참여 유도 | **지금까지 (성과)를 해냈고, (결과)까지 (기간) 남았어요. 과정을 같이 보고 싶다면 + CTA** |

🔑 **핵심 포인트**
- 목표는 **숫자와 기한을 붙여 구체적으로.** ('성공하고 싶다' → '올해 안에 2호점')
- 시리즈로 만들어 **'D-100', 'N일차'**처럼 업데이트하면 다음 편을 기다리게 된다.
- 마지막에 **'같이 지켜봐 달라'**는 참여 유도를 넣으세요. **팔로우 이유가 된다.**

### ⑧ 문제 상황 & 해결책

📍 **이럴 때**: 판매·문의로 직접 연결하고 싶을 때. **약속 → 문제 → 증거 → 제안**으로 이어지는 **가장 짧은 설득 구조**로, 광고 영상에도 그대로 쓸 수 있다.

| 단계 | 역할 | 템플릿 |
| --- | --- | --- |
| 1. 약속 (Promise) | 대담한 결과로 후킹 | 저는 (충격적인 결과)를 만들었어요 |
| 2. 문제 (Problem) | 해결 전 고통 | 처음엔 (고통1), (고통2), (고통3)로 고생했죠 |
| 3. 증거 (Proof) | 결과·사례·수치 | 하지만 (해결책)을 찾고 나서 (결과)가 나왔어요 |
| 4. 제안 (Proposal) | 결과를 만든 단계 또는 상품 제안 | **제가 따른 방법은 1( ), 2( ), 3( )입니다** |

🔑 **핵심 포인트**
- 약속(1단계)은 대담하게, **하지만 반드시 증명할 수 있는 내용만** 쓰세요.
- 증거(3단계)에는 **후기, 수치, 전후 사진 중 하나를 꼭 화면에 띄우세요.**
- **제안(4단계)은 한 가지 행동만.** DM, 링크, 댓글 중 하나만 고르세요.

### ⑨ 시련 – 승리 서사

📍 **이럴 때**: **'너는 못 해'라는 말을 듣고도 해낸 경험**이 있을 때.
감동 + 방법 + 편견 깨기까지 담아서, **길지만 가장 강력한 브랜딩 영상**이 된다.

| 단계 | 역할 | 템플릿 |
| --- | --- | --- |
| 1. 의심 | 나를 가뒀던 한계 | X년 전 사람들은 제가 절대 (결과)를 못 할 거라고 했어요 |
| 2. 초반 고생 | 노력했지만 안 된 시기 | (행동)을 했지만 계속 (나쁜 결과)만 나왔죠 |
| 3. 전환점 | 모든 걸 바꾼 한 가지 | (깨달음)을 알기 전까지는요 |
| 4. 해결책 | 방법·프레임워크 | 제가 만든 (N단계 방법): 1( ), 2( ), 3( ) |
| 5. 변화 | 바뀐 모습 | (이전)에서 (지금)으로 바뀌었고, (좋은 변화)까지 생겼어요 |
| 6. 편견 깨기 | 흔한 오해 반박 | **(결과)는 어렵지 않아요. 그동안 잘못된 방법을 썼을 뿐이에요** |

🔑 **핵심 포인트**
- 1단계 '의심'은 **실제로 들었던 말을 인용**하면 힘이 세진다. ("그걸로 무슨 돈을 벌어?")
- **4단계 해결책에 이름을 붙이세요.** '나만의 방법'이 곧 내 브랜드다.
- 6단계 편견 깨기는 **보는 사람에게 하는 말**로 끝내세요. **'당신도 할 수 있다'는 메시지가 공유를 부른다.**

## 채채 계정에 어떻게 적용하나

### 지금 첫 릴스 = ③ 나의 진솔한 이야기 구조여야 한다

**고정 1번으로 가장 추천하는 구조**라고 명시돼 있고, 지금 만드는 게 정확히 그거다.
현재 대본을 이 기준으로 보면 **두 군데가 어긋난다.**

| 기준 | 현재 대본 | |
| --- | --- | --- |
| **30초 안쪽** | **56초** | 🔴 거의 2배 |
| **5단계 목적에 타겟을 넣을 것** | 마무리에 **타겟이 없음** | 🔴 제일 큰 구멍 |

**5단계 목적**이 비어 있는 게 치명적이다. 자료의 문장이 이렇다.

> (결과)가 제 삶을 바꿨고, 이제 제 미션은 **(타겟)**이 (고민)에서 벗어나 (결과)를 얻도록 돕는 거예요.
> → *보는 사람이 '나를 위한 계정'이라고 느낄 때 팔로우합니다.*

현재 마무리는 "내가 혼자 부딪히면서 알게 된 것들… 성공하든 망하든 보여줄게"다.
**"누구를 위해"가 없다.** 바로 앞에서 타깃을 `뷰티샵 차리고 싶은데 아직 안 한 사람`으로
못 박았으니, **그 단어가 마무리에 들어가야 한다.**

### 길이 — 56초 vs 30초

자료는 30초를 권하지만, 이건 **「자기소개」 전용 기준**이고 근거도 명확하다
(*"자기소개는 길어지는 순간 자랑이 된다"*). 지금 대본은 숫자 구간과 사다리 구간이
길어서 자랑으로 기울 위험이 실제로 있다.

**다만 0:12 어려움·0:23 사다리는 자랑이 아니라 고생·과정이라 깎으면 손해다.**
깎을 곳은 **0:35 숫자 구간(8,000 / 2,000 / 투잡)**이다. 거기가 자랑에 제일 가깝다.

### 앞으로 쓸 구조 배정

| 콘텐츠 | 구조 |
| --- | --- |
| 첫 릴스 (소개편) | ③ 나의 진솔한 이야기 |
| **펀딩 과정 시리즈** | **⑦ 큰 꿈 & 인생 목표** ← 성과가 없어도 되는 유일한 구조, 초기 계정 추천 |
| 무료 모델 → 정가 8만 원 | ⑤ 돌파구 & 도전 (저장·공유 최다 구조) |
| 권리금 3,800 → 600 | ⑥ 인생 교훈 |
| 가림막 제품 판매 | ① 역경–성공 서사 / ⑧ 문제 상황 & 해결책 (**펀딩 이후**) |
| 아직 미정 — 소재 확인 필요 | ⑨ 시련–승리 서사 |

**⑦이 펀딩 시리즈에 정확히 맞는다.** "10/26까지 될까?"가 2단계(본격 도전)고,
"같이 지켜봐 달라"가 3단계 참여 유도다. **`D-3`, `N일차` 표기를 붙이라**는 것도 자료에 있다.

⑦ 3단계 템플릿을 그대로 채우면 이렇게 된다.

> 지금까지 **(샘플·공장·상세페이지)**를 해냈고, **(와디즈 신청 마감)**까지 **(3일)** 남았어요.
> 과정을 같이 보고 싶다면 팔로우해두세요.

### ⑧은 지금 못 쓴다 — 펀딩 이후다

⑧은 **판매용 구조**라 가림막에 쓰고 싶겠지만, 자료가 못을 박는다.

> *약속(1단계)은 대담하게, **하지만 반드시 증명할 수 있는 내용만** 쓰세요.*
> *증거(3단계)에는 **후기, 수치, 전후 사진 중 하나를 꼭** 화면에 띄우세요.*

**지금은 제품도 안 나왔고 후기도 수치도 없다.** 증거 칸이 비어 있는 상태로 ⑧을 쓰면
**약속만 큰 광고**가 된다. ⑧은 **첫 후기가 나온 뒤**에 쓴다. 그 전까지는 ⑦이다.

### ⑨를 쓰려면 이게 필요하다

⑨는 **'너는 못 해'라는 말을 실제로 들었어야** 성립한다. 1단계가 **실제 인용**이어야 힘이 붙는다.

**확인 필요** — 23살에 가게 차린다고 했을 때 주변에서 뭐라고 했는지,
반영구 배우러 다닐 때 들은 말이 있는지. **그 한 마디가 있으면 ⑨가 열린다.**
(권리금 내놨을 때 들은 "150만 원에 안 돼요?"는 ⑥ 인생 교훈 쪽에 더 맞는다.)
