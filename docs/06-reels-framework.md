# 스토리텔링 릴스 프레임워크 (참고 자료 정리)

> 출처: 「터지는 첫 릴스 만드는 tip」 (예안채널)
> 앞으로 대본 짤 때 이 기준으로 검토한다.

---

## 1. 왜 첫 영상을 스토리텔링형으로

- **첫 릴스는 계정의 얼굴이다.**
- 사람들은 완벽한 것보다 **진정성 있는 경험과 이야기**에 끌린다.
- **팔로우하는 이유 = "그 사람의 다음 이야기가 궁금해서."**
- 스토리텔링형은 **시청시간이 길어져서** 알고리즘이 더 퍼뜨린다.

### 팔로우가 일어나는 3단계

```
①  콘텐츠를 봄
    무드가 마음에 들거나, 화자가 하는 이야기가 궁금하면 멈춘다
        ↓
②  공유 또는 저장
    저장 = 와닿는 문구 / 나에게 유용한 정보
    공유 = 비슷한 상황의 사람에게 보낼 만한 내용
        ↓
③  계정이 궁금해짐
    "이거 뭐 올리는 계정이지?" → 프로필로 들어옴
```

→ **세 단계가 다 걸려야 팔로우가 된다.** 멈추기만 해서는 안 되고,
저장할 이유가 있어야 하고, 프로필이 받아줄 준비가 되어 있어야 한다.

## 2. 나의 이야기 — 큰 이야기와 쪼갠 이야기

### 큰 유형 5가지

| 유형 | 예시 |
| --- | --- |
| 나의 이야기 | 퇴사 후 육아하는 육아맘, 부업 도전기 |
| 목표 | 올해 나의 목표는 이직 |
| 시리즈물 | 7년 수험 끝낸 백수, 9가지에 도전 |
| 챌린지 | 앞으로 30일간 매일 콘텐츠 업로드하겠습니다 |
| **터닝포인트** | 내 인생의 터닝포인트 — 그 결과 지금 이 주제를 도전하게 됨 |

### 기본 구조

```
어려움 극복  →  결과  →  교훈
```

### 큰 이야기 → 쪼갠 이야기

큰 이야기 하나를 올리고, **거기서 파생되는 구체적인 이야기들**을 다음 릴스로 푼다.
그리고 그 사이사이에 **정보형 콘텐츠**를 섞는다.

**권장 믹스 순서**

```
스토리텔링 2 → 정보 3 → 스토리텔링 1 → 협찬 1 → 정보 4
```

## 3. 대본 구조 3가지

| 구조 | 흐름 |
| --- | --- |
| ① **경험에서 인사이트 뽑기** | 내 경험 → 의외의 사실 발견 → 나만의 관점 |
| ② **편견 깨부수기** | 기존의 통념 → 직접 겪은 반전 → 생각의 변화 |
| ③ **시행착오로 설득하기** | 실패·고민 → 해결의 실마리 → 경험에서 얻은 교훈 |

### 30초 시간 배분

| 구간 | 역할 | 시간 |
| --- | --- | --- |
| 도입 | 경험이나 문제로 시청자의 관심 끌기 | 0~5초 |
| 전개 | 경험 속 정보, 구체적인 사건 전달 | 5~20초 |
| 마무리 | 나만의 관점, 깨달음 또는 조언 | 20~30초 |

### 기획할 때 기억할 3가지

1. **경험은 구체적으로**
   "주식 투자를 시작했어요" < "처음 주식 투자로 손실 보고 매일 계좌만 확인했어요"
2. **정보는 하나만**
   30초 안에 많이 넣지 말고, 기억할 핵심 하나에 집중
3. **마무리는 나만의 관점으로**
   정보 전달로 끝내지 말고, 그 경험 이후 **무엇을 다르게 생각하고 행동하게 됐는지**

## 4. 공감될 만한 후킹 멘트

시청자가 **자기 상황으로 읽을 수 있는** 문장으로 연다.

예시 (원문)
- 새벽까지 편집했는데 조회수 300회…
- 평범한 직장인, 퇴근 후엔 녹초가 되는데 부업 언제 하나요?
- 직장인은 시간이 대체 어디서 나나요?

**채채 버전으로 바꾼다면**
- 하고 싶은 건 있는데, 뭘 해야 할지는 모르겠는 사람?
- 퇴근하고 나면 아무것도 하기 싫은데, 그래도 뭔가 하고는 싶고
- 회사 그만두고 싶은데 뭘 할지를 모르겠어서 못 그만두는 중

---

## 5. 핵심 한 줄

> 첫 영상이 반응을 얻는 이유는 꾸밈이나 인위적인 정보 공유가 아니라
> **"이 계정의 주인만이 할 수 있는 이야기"** 라고 인식되는 이야기를 올렸기 때문.

---

## 6. 대본 검토 체크리스트

새 대본을 짤 때마다 이걸로 걸러본다.

- [ ] 도입 5초 안에 **경험이나 문제**가 나오는가
- [ ] 경험이 **구체적**인가 (뭉뚱그린 표현 아닌가)
- [ ] 전달하려는 핵심이 **하나**인가 (두 개 이상이면 쪼갠다)
- [ ] 마무리가 정보가 아니라 **나만의 관점**인가
- [ ] **저장하거나 공유할 이유**가 있는가
- [ ] 보고 나서 **다음 이야기가 궁금해지는가**
- [ ] 이게 **채채만 할 수 있는 이야기**인가 (누구나 할 수 있으면 다시)
