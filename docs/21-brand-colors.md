# 채채 브랜드 컬러 (확정)

```
메인    버터 옐로우   #EBC97A
배경    오트 크림     #F3EDE3
글자    에스프레소    #3A2F28
서브    모카          #A8826A
```

## 비율 — 70 / 20 / 10

| 비율 | 색 | 쓰는 곳 |
| --- | --- | --- |
| 70% | 오트 크림 | 배경 전체 |
| 20% | 에스프레소 | 모든 글자 |
| **10%** | **버터 옐로우** | **강조 한 군데만** |
| 소량 | 모카 | 큰 숫자, 얇은 선, 라벨 박스 |

**버터 옐로우를 10% 넘게 쓰면 싸 보인다.** 한 화면에 **하이라이트 하나**가 원칙.

## 자리별

| | |
| --- | --- |
| 릴스 커버 | 사진 + 에스프레소 글자, 핵심 한 줄만 버터 옐로우 |
| 카드뉴스 | 오트 크림 배경, 에스프레소 글자, 강조 문장만 버터 옐로우 |
| 하이라이트 커버 | 오트 크림 바탕 + 에스프레소 아이콘 |
| 자료(노션) | 흰 배경 유지, 콜아웃만 버터 옐로우 |

## 쓰지 말 것

| ❌ | 왜 |
| --- | --- |
| 파랑 · 남색 · 빨강 | 웜톤 팔레트가 깨진다 |
| 형광 노랑 `#F5E34B` | 눈이 피로하고 톤이 낡아 보인다 → 버터 옐로우로 |
| 순검정 `#000000` | 웜톤 위에서 너무 딱딱하다 → **에스프레소로** |
| 순흰색 배경 | 차갑다 → 오트 크림으로 (단, 메모앱 목업 같은 카드는 흰색 OK) |

## 왜 이 색인가

- **버터 옐로우** — 밝고 들어오기 쉬운 색. 20대 여성 타깃에 맞고, 1편 커버의 노랑과 이어진다
- **웜 뉴트럴 베이스** — 뷰티·라이프스타일 피드에서 안 튀면서 정돈돼 보인다
- **순검정 대신 에스프레소** — 베이지 위에 순검정을 올리면 인쇄물처럼 딱딱해진다

## 적용할 것

- [ ] 1편 릴스 커버의 형광 노랑 → **버터 옐로우**로 교체 (아직 안 올렸으면 지금)
- [ ] 카드뉴스 전체
- [ ] 프로필 하이라이트 커버
