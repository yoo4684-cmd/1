## 1. 첫 릴스 — ③ 나의 진솔한 이야기

**고정 1번으로 가장 추천하는 구조.** 지금 대본이 이 틀이고, **5단계만 비어 있다.**

| 단계 | 채운 것 |
| --- | --- |
| 1. 도입 | 23살에 왁싱샵 차린 채채예요. 그전엔 평범한 치과위생사였어요 |
| 2. 갈등 | 직장을 오래 다닐 생각이 없었는데, 뭘 해야 할지를 모르겠더라고요 |
| 3. 깨달음 | 퇴근하고 일단 반영구부터 배우러 갔는데, **하나를 해보니까 그다음이 보이더라고요** |
| 4. 변화 | 무료 모델부터 3만, 5만, 8만 정가까지. 23살에 14평 내 샵을 차렸어요 |
| 5. 목적 | 🔴 **비어 있음** |

### 5단계를 이렇게 채운다

> 저도 그때 **물어볼 사람이 없어서** 혼자 다 부딪혔거든요.
> 이제 제가 하고 싶은 건 **뷰티샵 차리고 싶은데 뭐부터 할지 모르는 사람들**이
> 저처럼 헤매지 않게 하는 거예요.
>
> 성공하든 망하든 있는 그대로 보여줄게요. 팔로우해두고 지켜봐줘.

**`뷰티샵 차리고 싶은데 뭐부터 할지 모르는 사람`** — 이게 타겟 호명이다.
자료가 말하는 그대로: *보는 사람이 '나를 위한 계정'이라고 느낄 때 팔로우한다.*

지금 마무리("내가 알게 된 것들 보여줄게")는 **주어가 나**다.
바꾼 마무리는 **주어가 보는 사람**이다. 그 차이가 팔로우를 만든다.

## 2. 펀딩 시리즈 — ⑦ 큰 꿈 & 인생 목표

*성과가 없어도 만들 수 있는 유일한 구조. 보는 사람을 '응원하는 팬'으로 만든다. **초기 계정에 특히 추천.***
→ 팔로워가 거의 없는 지금 상황에 **정확히 맞는 단 하나의 구조**다.

| 단계 | 채운 것 |
| --- | --- |
| 1. 꿈 소개 | 왁싱샵 3년 하면서 계속 "이런 거 있으면 좋겠다" 했던 게 있었어요 |
| 2. 본격 도전 | 몇 년을 생각만 하다가, **멀쩡한 조명을 톱으로 잘라서 직접 만들어 쓴 날** 결심했어요. 될지 안 될지 몰랐지만 그냥 했죠 |
| 3. 진행 상황 | **지금까지 샘플이랑 공장, 상세페이지까지 해냈고, 와디즈 신청 마감이 오늘이에요. 과정 같이 보고 싶으면 팔로우해두세요** |

### 시리즈로 돌린다

자료가 **`D-100`, `N일차`처럼 업데이트하면 다음 편을 기다리게 된다**고 했다.
펀딩은 **마감일이 이미 있어서** 이 구조가 공짜로 굴러간다.

```
D-0   신청 넣는 날        "오늘이 마감이에요"
D+1   심사 기다리는 중
D+N   결과 (됐든 안 됐든)
그 뒤  오픈예정 → 본 펀딩 → D-day 카운트
```

떨어져도 2단계("될지 안 될지 몰랐지만 그냥 했죠")가 이미 깔려 있어서 **서사가 안 깨진다.**

## 3. 무료 모델 → 정가 8만 원 — ⑤ 돌파구 & 도전

*정보를 주면서도 이야기로 풀어내기 때문에 **저장과 공유가 가장 많이 나오는 구조.***

| 단계 | 채운 것 |
| --- | --- |
| 1. 문제 | 자격증은 땄는데 **손님이 0명**이었어요. 연습할 데도 없었고요 |
| 2. 돌파 | 그런데 몇 달 만에 **정가 8만 원**을 받게 됐어요 |
| 3. 해결법 | 베드쉐어를 구해서 **연습 공간부터** 만들었고, 무료 → 3만 → 5만 → 8만.<br>제가 따른 단계는 **1) 연습 공간 만들기 2) 무료로 사람 수 쌓기 3) 단계별로 가격 올리기** |

🔑 자료의 핵심 포인트가 그대로 적용된다.
- *1단계 문제는 **보는 사람도 겪고 있는 문제**여야 한다* → "손님이 0명"이 정확히 그거다
- ***2단계에서 결과를 먼저 던지고, 3단계에서 방법***을 푼다 → 8만 원을 먼저 말한다
- *방법은 **화면에 1, 2, 3 자막**을 띄우면 저장이 늘어난다*

## 4. 권리금 3,800 → 600 — ⑥ 인생 교훈

*완벽해 보이는 것보다 **실패를 인정하는 사람**이 훨씬 더 신뢰를 얻는다.*

| 단계 | 채운 것 |
| --- | --- |
| 1. 좌절 | **권리금 3,800만 원 주고 들어간 가게를 600만 원에 넘겼어요** |
| 2. 고통 | 3,500에 내놓고, 2,000으로 내리고, 1,000까지 내렸는데 **1년 동안 안 나갔어요** |
| 3. 해결 | 결국 600에 넘겼어요 |
| 4. 교훈 | **권리금은 들어갈 때가 아니라 나올 때를 생각하고 내는 거더라고요** |

🔑 *1단계는 충격적일수록 좋다. **'망했다', '0원'** 같은 단어가 스크롤을 멈추게 한다*
→ **"0원에라도 넘기려고 했어요"**를 2단계에 넣으면 더 세진다. (실제로 그랬으니 과장 아님)

🔑 *4단계 교훈은 **한 문장으로.** 짧고 명확한 교훈이 공유를 부른다*

## 지금은 안 맞는 구조 3개

쓰고 싶어도 **조건이 안 갖춰져서** 지금 쓰면 역효과다.

| 구조 | 왜 지금 안 되나 | 언제 열리나 |
| --- | --- | --- |
| **⑧ 문제 & 해결책** | *증거(3단계)에 후기·수치·전후 사진 중 하나를 꼭 띄우라*고 돼 있는데 **셋 다 없다.** 지금 쓰면 **약속만 큰 광고** | **첫 후기** 나온 뒤 |
| **① 역경–성공 서사** | 6단계가 **내 사업·서비스 CTA**인데 **팔 게 아직 없다** | 펀딩 오픈 후 |
| **⑨ 시련–승리 서사** | 1단계 '의심'이 **실제로 들었던 말 인용**이어야 하는데 그 소재가 없다 | **아래 질문에 답이 나오면** |
| ④ 비포 & 애프터 | *숫자·사진·화면으로 보여줄 성과*가 필요한데 **비포 사진이 있는지 미확인** | 사진 확인 후 |

### ⑨를 열려면

> **23살에 가게 차린다고 했을 때 주변에서 뭐라고 했나요?**
> 반영구 배우러 다닐 때, 치과 그만둔다고 했을 때 들은 말도 좋습니다.

⑨는 *"길지만 **가장 강력한 브랜딩 영상**"*이라고 돼 있다.
**"그걸로 무슨 돈을 벌어?" 같은 한 마디만 있으면** 이 구조가 통째로 열린다.
그리고 6단계 편견 깨기 — **"뷰티샵 창업, 어렵지 않아요. 그동안 순서를 몰랐을 뿐이에요"** —
가 타깃한테 정확히 꽂힌다.
