# 판매 채널 결정 — 와디즈 vs 스마트스토어 예약주문

> 상황: 샘플 진행 중. 와디즈 블랙버드 신청 기간을 맞출 수 있을지 불확실.
> 질문: 스마트스토어에 "한 달 뒤 배송"으로 올리면 그것도 선주문 아닌가?

---

## 먼저 질문에 답하면 — 맞아요, 근데 책임이 달라요

**기능적으로는 선주문 맞습니다.** 네이버 스마트스토어에 예약구매 기능이 있고,
발송예정일을 지정해서 미리 주문을 받을 수 있어요.

문제는 **같은 "선주문"인데 법적·심리적 위치가 다르다**는 거예요.

| | 와디즈 펀딩 | 스마트스토어 예약주문 |
| --- | --- | --- |
| 소비자 인식 | **"만드는 걸 돕는다"** | **"물건을 산다"** |
| 지연에 대한 기대 | 어느 정도 감수 | **지키는 게 당연** |
| 지연 시 | 공지 의무 | **지연배상 + 플랫폼 패널티** |
| 플랫폼 트래픽 | **있음** (와디즈 내부 노출) | 거의 없음 (신규 스토어) |
| 수수료 | 높음 | 낮음 |
| 재고 리스크 | 펀딩액으로 생산 | **본인 부담** |

### 핵심은 이거예요

**와디즈는 "아직 없는 물건"을 파는 게 제도적으로 허용된 구조**예요.
참여자도 기다릴 각오를 하고 들어옵니다.

**스마트스토어는 "있는 물건"을 파는 곳**이에요.
예약구매라도 소비자는 "주문했으니 그날 온다"고 생각합니다.
날짜를 못 지키면 환불 요구 + 네이버 발송지연 패널티(판매자 등급·노출 불이익)가 같이 와요.

> 첫 제품에서 지연 사고가 나면 **브랜드가 거기서 끝납니다.**
> BESI는 한 번 팔고 말 게 아니라 **계속 제품을 낼 브랜드**잖아요.

*실제 예약구매 설정 가능 기간, 발송지연 패널티 기준, 지연배상 규정은
네이버 판매자센터와 전자상거래법 기준으로 **직접 확인하고 쓰세요.** 수시로 바뀝니다.*

---

## 그런데 더 중요한 게 있어요

### 샘플 확정 전에는 **어느 쪽도 오픈하지 마세요**

이유 세 가지예요.

**① 실물 없이는 안 팔려요**
와디즈 상세페이지에서 전환을 만드는 건 **실물 사진과 영상**이에요.
렌더링과 설명만으로는 거의 안 팔립니다. 지금 상세페이지에도
"→ 장갑 낀 손 + 크롬 관절 컷", "→ LIGHT ON/OFF 컷" 처럼 **실물 컷 자리가 비어 있어요.**

**② 샘플에서 발견될 문제가 아직 안 나왔어요**
첫 샘플에서 안 나오고 2차·3차에서 나오는 문제가 많아요.
오픈하고 나서 발견하면 **일정을 못 바꿉니다.**

**③ 일정을 맞추려고 무리하면 그 비용이 더 커요**
한 회차 미루는 비용 < 준비 안 된 채 오픈하는 비용.
거의 항상 그렇습니다.

---

## 지금 채널을 결정할 필요가 없어요

이게 제일 중요한 얘기예요.

**지금 해야 할 건 채널 결정이 아니라 "대기명단 쌓기"입니다.**

| | 결제 받는 선주문 | 대기명단 (알림 신청) |
| --- | --- | --- |
| 리스크 | 지연 시 환불·배상 | **0** |
| 일정 압박 | 있음 | **없음** |
| MOQ 판단 | 가능 | **가능** |
| 쓸 수 있는 곳 | 그 채널만 | **와디즈·스토어 어디든** |

**결제 없이 명단만 모으면 리스크가 없고, 그 숫자로 초도 물량을 정할 수 있어요.**
그리고 그 명단은 **나중에 어느 채널을 고르든 그대로 쓸 수 있습니다.**

### 지금 할 수 있는 것

- 인스타 댓글·DM: **"먼저 받아볼 사람 댓글 남겨줘"**
- 네이버폼 / 구글폼: 이름 + 연락처 + "몇 개 필요하세요?"
- 스토리 투표: "이거 나오면 살 것 같다 / 고민된다"

**"몇 개 필요하세요?"** 를 꼭 물어보세요. 샵 하나에 베드가 여러 개면
한 사람이 2~3개 사요. **인원 수와 수량이 다릅니다.**

## 그래서 어떻게 결정하냐면

```
샘플이 확정됐나?
│
├─ 아니오 ──→ 어느 채널도 오픈하지 않는다
│             대기명단만 쌓으면서 콘텐츠 계속
│
└─ 예 ──→ 내가 모은 명단이 초도 물량을 커버하나?
          │
          ├─ 아니오 ──→ 와디즈 (트래픽이 필요함)
          │
          └─ 예 ──→ 스마트스토어도 가능 (수수료 아낌)
```

### 와디즈를 쓰는 진짜 이유는 돈이 아니라 트래픽이에요

내가 이미 살 사람을 다 모았으면 와디즈 수수료를 낼 이유가 없어요.
반대로 **사람이 없으면 와디즈 내부 트래픽이 절실합니다.**

**지금 채채 계정은 사실상 0명이에요.** 그래서 현재 기준으로는 **와디즈가 맞아요.**
다만 콘텐츠를 두세 달 돌려서 왁싱 원장 팔로워가 쌓이면 **그 계산이 바뀝니다.**

---

## 블랙버드에 대해

블랙버드 혜택이 얼마나 큰지는 **와디즈에서 직접 확인하셔야 해요.**
(신청 조건·회차·혜택이 자주 바뀝니다)

판단 기준은 하나예요.

> **"이 회차를 놓치면 다음 회차에 못 들어가나?"**

- 다음 회차가 있다 → **무조건 미루세요.** 샘플이 우선입니다.
- 이번이 마지막이거나 조건이 크게 불리해진다 → 그때 비교해볼 값어치가 있어요.

다만 그 경우에도 **샘플 없이 오픈하는 선택지는 빼고** 비교하세요.
"블랙버드 혜택" vs "브랜드 신뢰"는 비교 대상이 아닙니다.

---

## 콘텐츠 쪽은 어떻게 되냐면

**사실 거의 안 바뀝니다.** 오히려 편해져요.

| | 날짜 있을 때 | 날짜 미정일 때 |
| --- | --- | --- |
| 목표 | 알림신청 전환 | **대기명단 + 팔로워** |
| 제품 비중 | 40~50% (한시) | **20~25%** |
| 급한 정도 | D-day 역산 | 여유 있게 |

날짜가 없으면 **D-10 스퍼트 구간만 빠지고 나머지는 그대로**예요.
오히려 0단계·1단계를 천천히 제대로 쌓을 시간이 생깁니다.

그리고 그 기간에 쌓은 대기명단이 **나중에 어느 채널을 고르든 그대로 쓰여요.**
**지금 콘텐츠를 멈출 이유는 전혀 없습니다.**

---

## 정리

1. 스마트스토어 예약주문도 선주문 맞다. 다만 **지연 책임이 훨씬 무겁다.**
2. **샘플 확정 전에는 어느 쪽도 오픈하지 않는다.**
3. 지금은 채널 결정 말고 **대기명단**을 쌓는다. 리스크 0, 어디든 쓸 수 있음.
4. 팔로워 0인 현재 기준으로는 **와디즈가 맞다.** 트래픽 때문에.
5. 블랙버드는 **다음 회차가 있으면 미룬다.**
