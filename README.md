## 창업비용 계산기

**https://claude.ai/code/artifact/8c96aded-4e5e-438c-bf06-a70f65d54598**

체크리스트 PDF에 QR코드 / 링크로 연결할 페이지.

- 초기 투자금, 월 고정비, 월 순이익, 투자금 회수 기간 계산
- 보증금을 뺀 **돌려받기 어려운 돈** 기준 회수 기간도 같이 보여줌
- 매물 3개까지 저장해서 비교 (체크리스트 항목 1과 연결)
- 입력값은 브라우저에만 저장되고 서버로 안 넘어감

수정하려면 `calculator/index.html` 을 고친 뒤 같은 URL로 다시 배포하면 됨.

## 작업 원칙

체크리스트는 한 번에 완성하지 않는다.
**항목 하나 제안 → 넣기 / 빼기 / 수정 결정 → 다음 항목** 순서로 진행한다.
